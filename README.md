A make.fun bounty entry for **Fortune Cookies for Machines**: a small
Node program (`main.ts`, program/v1) that writes one fortune-cookie
fortune meant for an AI agent to `/output/entry.txt` — a single line of
at most 200 characters, judged head-to-head on wit and surprise.

Bounty page: https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e

## Run it

```sh
node main.ts   # writes the fortune to /output/entry.txt
```
